# Smart Tools & Aluminum

A modern, responsive product website for **Smart Tools & Aluminum**, showcasing aluminum and related products through a clean product catalog and contact experience.

## 🌐 Website

This project is designed as a **static website** and can be deployed directly using **GitHub Pages**.

- 📦 Product catalog
- 🖼️ Product image gallery
- 📱 Responsive design
- 📞 Contact page
- ⚡ Fast static-site deployment
- 🔗 Simple HTML-based navigation
- 📁 All website assets stored in the repository root for simple GitHub Pages deployment

## 🚀 Deploy with GitHub Pages

### 1. Create a repository

Create a new repository on GitHub.

Example:

```text
smart-tools-aluminum
```

### 2. Upload the website

Upload all files from this project directly into the repository root.

Make sure `index.html` is located at:

```text
/
└── index.html
```

### 3. Enable GitHub Pages

Go to:

```text
Repository
→ Settings
→ Pages
```

Under **Build and deployment**:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

Click **Save**.

GitHub will automatically build and publish the website.

No backend or database is required.

```text

```

directly in a browser, or use a local development server such as VS Code Live Server.

## 📌 Deployment Notes

For GitHub Pages:

- Keep `index.html` in the repository root.
- Keep product images in the repository root.
- Preserve the filenames used by the HTML files.
- Do not rename image files without updating their references.
- GitHub Pages is suitable because this project is a static website.
